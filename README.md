# Introduction to Data Analysis with Python

Welcome to the course repository for **Introduction to Data Analysis with Python**, given at SciencesPo for the fall semester 2026/2027.

This repository contains the notebooks, exercises, datasets, examples,
and other materials used throughout the class. The course is designed to
take you from the fundamentals of Python programming to the core
workflow of data analysis: importing data, cleaning it, manipulating it,
visualizing it, and carrying out exploratory data analysis (EDA).

## Course contents

The course is organized into the following modules.

| Session | Topics |
|---|---|
| **01** | **Introduction to Python** — Python syntax, variables, types, expressions, basic input/output, notebooks, and the Python workflow |
| **02** | **Control Flow** — Boolean logic, `if`/`elif`/`else`, `for` loops, `while` loops, and iteration |
| **03** | **Defining Functions** — Function definitions, parameters, return values, scope, reusable code, and documentation |
| **04** | **Data Structures: Lists** — Creating and manipulating lists, indexing, slicing, iteration, and common list operations |
| **05** | **Data Structures: Tuples, Sets, and Dictionaries** — Immutable sequences, sets, key-value structures, membership, and practical data organization |
| **06** | **Recap: Types, Functions, and Structures** — Consolidation of Python fundamentals and preparation for data-analysis libraries |
| **07** | **NumPy and Pandas** — Arrays, vectorized operations, Series, DataFrames, indexing, and basic tabular analysis |
| **08** | **Importing and Cleaning Data** — Reading datasets, inspecting data, missing values, duplicates, data types, and data-quality problems |
| **09** | **Data Manipulation** — Filtering, sorting, grouping, aggregation, merging, transforming, and reshaping data |
| **10** | **Data Visualization** — Choosing appropriate charts, creating plots, labeling figures, and communicating patterns |
| **11** | **Exploratory Data Analysis** — Asking questions, summarizing data, exploring relationships, detecting patterns and anomalies, and interpreting results |
| **12** | **Recap** — Review of the complete workflow and preparation for the final project |
